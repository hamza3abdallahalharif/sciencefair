Research Question

Do distractions affect the human memory?

Hypothesis

If distractions increase, memory accuracy will decrease.

Variables

Independent: Amount of distraction
Dependent: Memory performance
Controlled: Environment, time, number of items

Materials

List of words, timer, distraction sounds, notebook

Procedure

1) Show participants a list of words. 2) Add distraction at different levels. 3) Test recall accuracy. 4) Record the results.

Results & Conclusion

Memory accuracy decreased as distractions increased. Conclusion: Distractions negatively impact human memory.
